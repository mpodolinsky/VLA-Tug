Anticipate the failure. Name its mode. Bound the errors.

A small probe reads the latent layers of a Vision-Language-Action model while it acts. It raises an alarm before the failure, predicts how the policy fails, and its alarm threshold is calibrated to hold false-alarm and missed-detection targets.

Abstract

Vision-Language-Action models (VLAs) enable general-purpose embodied intelligence, but their performance is brittle under distribution shift, where unanticipated failures can damage equipment or endanger people. Deploying VLAs in real-world systems therefore requires a runtime monitor that is timely, calibrated, and informative while being efficient enough to run on the edge. Existing methods fail to fulfill these requirements. We present VLA-Tug, a lightweight probe over the latent layers of a VLA backbone that improves early failure detection and bounds the missed-detection and false-alarm rates, with minimal inference overhead. We show that supervising on the pre-failure segment of a trajectory increases early failure detection at matched false-positive rates by up to 30% over the strongest learned baseline. Under shift to unseen tasks, the bounds on missed-detection and false-alarm rates remain valid in up to 86% of runs, versus at most 21% for baselines. Unlike existing methods, VLA-Tug predicts the failure mode to enable corrective actions, raising top-3 accuracy on unseen tasks by up to 44% over a majority baseline. We release a dataset of 3,180 annotated manipulation episodes to support future work on latent failure detection in VLAs.

Probe the latent layers. Calibrate the alarm.

1

Pool

Average the backbone embedding of every policy step over the agent-image, wrist-image and language tokens: a 6144-d vector per step.

2

Train

Train a probe on the steps that precede a failure: an LSTM over the embeddings with a failure-score head, a failure-mode head and a semantic (CLIP) head.

3

Calibrate

Set the alarm threshold on held-out rollouts with max-conformal prediction or Learn-then-Test, which bounds the false-positive rate and the early true-positive rate together.

4

Evaluate

Score against annotated failure times: the area under the early true-positive rate versus false-positive rate curve up to 40%.

Code and reproduction

The code covers the probe, the calibration (SAFE band, max-conformal, Learn-then-Test), the baselines, the metrics and the scripts that produce the paper's tables and figures.

pip install -e ".[dev]"
python -m cli.download liberox_groot       # pooled features, targets, manifest, splits
python -m cli.train --datasets liberox_groot
python -m cli.evaluate --datasets liberox_groot
python -m cli.figures                      # main table, ablations, curves

These commands are taken from the repository README. During review the code is at the anonymous mirror linked above.
